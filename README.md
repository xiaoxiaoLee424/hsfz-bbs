# HSFZ BBS · 华附校园论坛

✨一个属于华附人自己的网上家园：学习、年级、球友、生活、交易，一个都不少。

**在线访问：[https://bbs.hsfz-bbs.cn](https://bbs.hsfz-bbs.cn)**

## 🌟功能介绍

### 七大分区 · 23 个板块

| 分区 | 板块 |
| --- | --- |
| 学习成长 | 学习互助 · 考试交流 · 文学创作 · 竞赛升学 |
| 年级群 | 初一专区 · 初二专区 · 初三专区 · 高一专区 · 高二专区 · 高三专区 |
| 球友 | 篮球 · 足球 · 板球 · 羽毛球 · 乒乓球 · 排球 · 网球 · 匹克球 |
| 生活娱乐 | 美食推荐 · 社团活动 · 校园闲聊 |
| 交易互助 | 跳蚤市场 · 失物招领 |
| 游戏 | 游戏讨论 |
| 情感联结 | 表白墙 · 校园回忆 · 校友交流 |
| 官方 | 站务公告 |

其中「年级群」只有本年级的同学可以发言，像年级群一样，但不会被打扰。「表白墙」支持匿名发表，大胆说出你的心意（管理员可见作者以维护秩序）。

### 🌟发帖带图

发帖时最多添加 4 张照片，自动压缩，图文并茂地记录校园生活。表白墙发帖还可以选择匿名。

### 🌟校园动态横幅

首页顶部有一条自动滚动的横幅位：社团招新、比赛组队、失物招领、活动预告都能投稿。可选预设渐变色卡，也能上传自己的背景图；提交后进入审核，管理员通过后才会投放，并可随时排序或下线。

### 🌟发帖可见范围

发帖和回复都可以设置可见范围：所有人、仅关注者、仅自己。非公开内容不会出现在首页/板块/搜索里，只有作者、管理员和（关注者可见时的）粉丝能看到；楼层编号和引用关系不受影响。

### 🌟头衔系统

发帖回帖自动升级：新入校 → 校园新人 → 活跃同学 → 校园达人 → 传奇学长。表现优秀的同学还会被授予金色专属头衔（比如"板球队长""食堂鉴定师"）。

### 🌟帖子互动

回复、点赞、收藏一个不少，还有全站搜索和首页热门话题榜。被回复、被引用、被 @、被点赞时，「我的消息」会出现红点提醒，点进通知可直接跳到对应楼层。私信功能支持与同学一对一交流。

回复可以删除：作者本人、帖子楼主和管理员都能删（两步确认）；删除后保留楼层占位，楼层号不变，图片与附件一并清理。

### 自定义头像与深浅主题

上传自己喜欢的头像（不设置也有字母头像），白天浅色、晚上深色，一键切换。

### 🌟联系管理员

在「我的消息」里发工单：申请头衔、提改进建议、举报内容，管理员会逐条回复。

## 扩展内容与互动

- 管理员在 `/admin/emojis` 上传不超过 512KB 的 PNG 或自包含基础 SVG；SVG 经校验后转换为透明 PNG。名称固定，停用只隐藏选择器条目，旧帖继续显示。
- 发帖、回复和预览支持 `:表情名称:`。代码、公式与链接中的短代码保持原样。
- BBCode 支持 `[b]`、`[i]`、`[u]`、`[s]`、`[spoiler]`；块级 `[details="标题"]`、`[quote thread=主题ID reply=回复ID]` 的开始和结束标签需独占一行。主帖使用 `reply=0`。
- 选中正文后可插入或复制引用；引用文本为快照，来源链接及反向引用仍经过访问检查。
- 相对站内链接 `/t/ID`、`/t/ID#reply-ID` 和正式站点同格式完整链接可显示访问权限感知的预览卡片。
- 主帖和回复支持完整 Emoji 目录与校园自定义表情；每人可参与多种 Reaction，已有 Chip 全量换行展示。Heart Like 独立于 Emoji Reaction，只有 Like 影响获赞统计和热门排序。
- 正文支持粘贴图片、拖拽或选择图片和普通附件，显示进度并可取消、手动重试；最多两个并发上传，网络错误及临时服务错误最多尝试三次。发帖合计最多4张、回复2张（含原图库），图片与附件合计10MB。正文图片经过权限路由访问。
- 正文上传暂存24小时；过期暂存、已删除内容的文件及中断上传的孤立文件通过清理脚本回收，上传时也会触发清理。每用户正文上传32MB，全站512MB，与既有文档附件配额分别计算。备份脚本会随 `attachments/` 一起备份这些图片。

## 🌟参与共建

这是一个由学生发起的开源项目，欢迎每一位同学参与建设，方式不限：

- **有点子**：新板块、新功能的想法，直接在论坛「我的消息」里发工单，或到仓库提 [Issue](../../issues)；
- **发现 bug**：页面报错、显示不对，提 [Issue](../../issues) 告诉我们就好；
- **会（或想学）写代码**：Fork 本仓库，改动后提交 PR，修一个错别字也算贡献。前端（React / Tailwind）、后端（Next.js / SQLite）、界面设计、文档文案，都需要人手；
- **不会代码也没关系**：写使用教程、帮忙测试找 bug，同样是宝贵的贡献。

每一个 Issue 和 PR 都会被认真对待。

### 本地存储维护

文件继续保存在 `HSFZ_DATA_DIR` 指定的本地数据目录。正文上传位于 `attachments/inline/`，现有备份命令会包含这些文件。

单次清理：`npm run uploads:cleanup`。持续清理：`npm run uploads:cleanup -- --watch`，每十分钟运行一次。命令必须使用与网页服务相同的数据目录和加密密钥。

本地测试可用 `node --env-file=.env.development.local --import tsx scripts/cleanup-uploads.mts --watch` 启动。当前测试端已启动独立清理进程，日志位于 `data/local-test/cleanup.log`。该进程不包含开机自启配置。

### 帖子 UI（设计包 v1.0）

帖子采用头像与正文双列、细分隔线和轻量操作栏。Post Quote 有来源小头像、用户名及永久链接，不显示楼层；Plain Quote 只显示左边线和内容。选区引用只插入正文，显式 Reply 目标单独保存；直接回复可展开摘要并跳转主时间线。

Emoji Picker 使用本地完整数据和中文资源，包含分类、搜索、真实最近使用和自定义表情。底部顺序为 Emoji Picker、独立 Heart Like、复制链接、More、回复。零 Reaction 不显示默认 Chip。旧 heart 迁移为 Like，其他旧反应迁移为对应 Emoji，旧表保留。
